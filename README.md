# Sales Performance Dashboard — Task 4

## Project overview
This beginner-friendly project demonstrates an interactive sales dashboard for business stakeholders. It includes KPI cards, region/category filters, regional and category comparisons, and a monthly sales trend.

## Files
- `sales_dataset.csv` — sample order-level data (240 records).
- `sales_dashboard_workbook.xlsx` — Excel workbook with raw data, KPI summary, and charts.
- `interactive_sales_dashboard.html` — interactive dashboard; open it in a web browser.
- `dashboard_summary.pptx` — short presentation explaining the project.

## How to use
1. Open `sales_dashboard_workbook.xlsx` in Excel or a compatible spreadsheet app.
2. Open `interactive_sales_dashboard.html` in Chrome, Edge, or Firefox.
3. Change the Region and Category filters to explore the dashboard.
4. Review `dashboard_summary.pptx` and edit the name/class details if your mentor requires them.

## Dataset note
The dataset is generated sample data for learning and demonstration. It is not sourced from a real company or Kaggle. Do not present the sample figures as actual business results. If your internship requires a Kaggle dataset, replace this CSV with a dataset you are permitted to use and update the workbook/dashboard.

## KPI definitions
- Total Sales: sum of sales values.
- Total Profit: sum of profit values (sales minus cost).
- Orders: number of order records.
- Average Order Value: total sales divided by the number of order records.
